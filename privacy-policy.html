01Overview

Short version: VKT VeilMate covers your browser so other people cannot see it. It does not collect, transmit or sell anything. Your password never leaves your device, and it is never stored in readable form.

VKT VeilMate draws a full-screen overlay over your tabs when you lock the browser, and removes it when you unlock. It works entirely inside your browser profile. There is no account and no server-side copy of your data. The single optional exception is Pro cross-device sync, which uses the browser's own sync storage and never passes through a server of ours.

03What is never collected

  • ❌ No page content, page titles, URLs, form data, keystrokes or screenshots
  • ❌ No password in readable form — only the derived hash is kept
  • ❌ No analytics, telemetry, crash reports or advertising identifiers
  • ❌ No account, e-mail address or profile

04Network requests

VKT VeilMate makes a network request in exactly one situation: when you activate a licence key, or when it later re-validates an existing licence. That request goes to api.annmax1983.com and contains the licence key you entered, a random install ID generated locally, and basic browser metadata (browser name and major version, UI language, time zone, user agent string).

No browsing data is included. If you never activate a licence, the extension makes no network requests at all. The overlay, the password check and every automatic lock work entirely offline.

05Cross-device sync

When you turn sync on, VKT VeilMate writes one small settings object into chrome.storage.sync — the browser's own sync storage. In Chrome that channel belongs to your Google account, in Edge to your Microsoft account, in Firefox to your Firefox account. The three are separate and never exchange data. We run no server on this path and cannot read or restore what is stored there.

The synchronized object contains preference fields only: clock settings, auto-lock toggles and timers, the quick-unlock window, the lock-screen message, the built-in gradient you picked, and the domain list that controls which sites the curtain covers. It never contains your password or its hash, your biometric credential ID, your unlock log, or an uploaded wallpaper — the last of these is far larger than the 8 KB per-item sync limit. Turning sync off deletes the stored copy.

The content script runs on http and https pages so it can draw the overlay there. It does not read page content, does not modify the page, and only communicates with VKT VeilMate's own service worker.

07Biometrics

If you enable biometric unlock (Pro), the browser's platform authenticator (Windows Hello, Touch ID, …) is used to confirm it is you. The biometric data itself never reaches the extension — the extension only receives and stores a credential ID. You can remove it at any time from the settings page.

08Data removal

  • Erase all settings in the options page removes the password and every setting, and deletes the synced copy.
  • Uninstalling the extension deletes all locally stored data — and, as the only way out of a forgotten password, also the wallpaper and every setting.
  • We hold no copy of your data, so there is nothing for us to delete on a server.

09Children

VKT VeilMate is a general-purpose utility and is not directed at children under 13.
