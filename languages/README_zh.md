给浏览器盖一块布：点一下遮住所有标签，解锁后页面原封不动 —— 不重载、表单不消失、视频不断流。

## 为什么选择 VKT VeilMate？

你去接杯咖啡，回来时发现有人扫了一眼你的屏幕：写了一半的邮件、网银标签页、一条私信。你要的是一块能盖住浏览器的布，不是一个安全产品。

现有的"浏览器锁"插件通常把两件事都做砸了：

| 它们的做法 | 代价 |
|---|---|
| 把所有标签导航到锁屏页 | 解锁后全部重载：表单没了、视频从头开始、单页应用状态全丢 |
| 宣称"防止未经授权访问" | 新配置、隐身窗口、任务管理器随便绕过，评论区一片一星 |

VKT VeilMate 的选择正好相反：

| 我们的做法 | 结果 |
|---|---|
| **只遮不跳转** —— 往每个页面注入一层 shadow DOM 遮罩 | 解锁瞬时完成，一个字节都不丢 |
| **把做不到的说出来** —— 写在设置页，也写在商店文案里 | 不给人过高的期待，也就不用为做不到的事挨一星 |
| **没有回头路** —— 没有恢复码、没有重置接口，锁定状态还能挺过浏览器重启 | 能绕过去的布不叫布；忘了密码只能移除扩展，而每个界面上都写着这句话 |

## 使用说明

### 第一次使用

1. 点工具栏图标 → **设置密码**。没有恢复码可抄，请把密码本身写在安全的地方。
2. 离开座位时点 **立即锁定**。
3. 在锁屏页用密码解锁，Pro 可用生物识别。

### 锁定范围怎么配

域名匹配按后缀、以点号为边界：`example.com` 覆盖 `example.com`、`www.example.com`、`a.b.example.com`，但不覆盖 `notexample.com`。协议头、开头的 `www.`、路径、端口、通配符前缀都会自动剥掉，单独一个 `com` 会被拒绝。

没有主机名的页面（`chrome://`、`file://`、`about:blank`、本地 PDF、扩展页）一律遮住，不受名单影响 —— 名单只对 http 与 https 生效。

### 忘记密码怎么办

只有一条路：**在 `chrome://extensions` 里移除扩展，然后重新安装。**

这也会清空壁纸和全部设置。没有恢复码、没有重置接口、也没有哪个客服能帮你解开 —— 能绕过的锁不叫锁。关掉浏览器同样没用：锁定状态存在 `storage.local` 里，重启后还在。

锁屏页的「忘记密码」面板会直接链到 `chrome://extensions/?id=<本扩展>`，所以你不会被困住，只是没有捷径。

## 工作原理

```
触发（按钮 / 右键菜单 / 闲置 / 失焦 / 系统锁屏 / 启动 / 定时）
  → 锁定状态写入 storage.local（挺过浏览器重启）
  → 对每个 http(s) 标签：tabs.sendMessage({type:'veil:lock'}) → 注入遮罩
  → 无法注入的标签：记住 URL，tabs.update(lock.html)
  → tabs.onCreated / tabs.onUpdated 继续拦截新出现的一切
  → windows.onCreated 覆盖 Ctrl+N、"在新窗口打开" 和隐身窗口
  → chrome://extensions/?id=<自己> 是唯一放行的内置页，保证扩展总能被移除
解锁
  → 在扩展页里校验密码 / WebAuthn
  → 清状态、移除遮罩、把被替换的标签原位恢复
```

几个值得知道的设计决定：

- **密码只在扩展页面里输入。** 网页自己的 JavaScript 永远看不到那个输入框，任何站点都嗅不到。
- **哈希在 service worker 里完成。** 只存 `{salt, iter, hash}`，密码本身从不落盘。
- **恒定时间比较。** 哈希比对不泄露时间信息。
- **遮罩跑在封闭 shadow root 里。** 页面脚本进不去、也改不了里面的样式。承载它的宿主节点在页面里，站点样式表可以针对它 —— 所以关键属性都按行内 `!important` 写入，另有守卫在遮罩被删掉或藏起来时补回去。

## 常见问题

**关掉浏览器还能保持锁定吗？** 能。锁定状态写在 `storage.local`，下次打开浏览器仍是锁定状态，直到你解锁。

**它是安全产品吗？** 不是。它挡住的是路过的人。能控制这台机器的人可以在 `chrome://extensions` 里停用它、换一个浏览器配置，或者在任务管理器里结束浏览器。这几条同样写在商店文案里。

**为什么没有密码找回？** 恢复码就是第二把钥匙，第二把钥匙就是后门。唯一出路是移除扩展，这一点在锁屏页上就写着。

**生物识别是不是第二条进门的路？** 它是一条捷径，不是第二把钥匙。密码校验在后台脚本里，两处提交密码的地方——解锁和改密码——共用同一个计数器与冷却；免密窗口完全不校验密码，它只在真正解锁后的几分钟内有效，并在活动日志里记一条 `quick`。但如果你能在扩展页打开 DevTools，你就能调用扩展自己的消息接口，这一点没有哪个扩展挡得住。把生物识别当作「少打几个字」，别当作「更安全」。

**连错五次会怎样？** 先停 30 秒，之后 2 分钟、10 分钟、30 分钟，最后每小时一次。计数器按设备记录，并且能在活动日志里看到。

**会上传什么吗？** 不上传页面内容、网址、按键，也不截图。唯一的外部请求是许可证激活与校验。

**免费版为什么把名单限制在 10 个域名？** 免费模式是"除名单外全遮"，短名单足够覆盖真实场景（网页邮箱、日历、正在读的那一页）。反过来那套"只遮…"，才是工作笔记本上要用的，放在 Pro 里。

**一份许可证能在两个浏览器上用吗？** 可以，一份许可证激活两个浏览器，从其中一个移除后名额会释放。

## 隐私说明

- 没有统计、没有遥测、没有广告、不要账号。
- 页面内容、网址、标题、按键都不离开浏览器。
- 壁纸和锁屏提示语留在你的设备上：上传的图片会被缩放并保存在当前浏览器配置里，不会发到任何地方。
- 跨设备同步（Pro）使用 `chrome.storage.sync`，也就是浏览器自己的同步通道。这条路径上没有我们的服务器，我们也读不到。密码被刻意排除在同步之外，自定义壁纸超出配额，所以只有偏好字段会同步。
- 唯一的外部请求是许可证激活 / 校验，且只在你粘贴密钥后发生。

- [完整隐私条款](https://annmax1983.github.io/vkt-veil-mate/privacy-policy.html)

### 权限说明

| 权限 | 用途 |
|---|---|
| `storage` | 保存设置（只存哈希）、持久锁定状态，以及通过 `storage.sync` 同步 Pro 数据 |
| `tabs` | 遮盖标签，锁定期间拦截新标签与手输网址 |
| `windows` | 响应窗口焦点变化，实现失焦自动锁 |
| `idle` | 闲置自动锁 |
| `alarms` | 定时锁与延时失焦锁，不依赖后台脚本常驻 |
| `contextMenus` | 右键菜单（锁住全部 / 保持此站可读） |
| `https://api.annmax1983.com/*` | 仅用于许可证激活与校验 |

内容脚本运行在 `http://*/*` 与 `https://*/*` 上，只做一件事：service worker 让它画遮罩时，它画遮罩。
