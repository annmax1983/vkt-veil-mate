# VKT VeilMate

[English](../README.md) | [中文](README_zh.md) | [Deutsch](README_de.md) | [Español](README_es.md) | 日本語 | [Français](README_fr.md)

ブラウザに一枚かけるツール：ワンクリックですべてのタブを覆い、解除すればページはそのまま —— 再読み込みなし、フォームは消えず、動画も途切れません。

> Chrome · Edge · Firefox · Manifest V3 · 最小限の権限 · 解析なし · すべてローカル

---

## なぜ VKT VeilMate なのか

コーヒーを取りに行って戻ると、誰かが画面を一瞥していた。書きかけのメール、ネットバンキングのタブ、私的なメッセージ。欲しいのはブラウザに掛ける一枚の布であって、セキュリティ製品ではありません。

既存の「ブラウザロック」拡張機能は、たいてい次のどちらかを失敗します。

| よくあるやり方 | 代償 |
|---|---|
| すべてのタブをロック画面へ遷移させる | 解除時に全部再読み込み。フォームは消え、動画は最初から、SPA の状態は破棄される |
| 「不正アクセスを防ぐ」と謳う | 新しいプロファイル、シークレットウィンドウ、タスクマネージャーで簡単に迂回され、レビューは星ひとつで埋まる |

VKT VeilMate は逆の立場を取ります。

| 私たちのやり方 | 結果 |
|---|---|
| **覆うだけで遷移しない** —— 各ページに shadow DOM のオーバーレイを重ねる | 解除は一瞬で、失われるものは何もない |
| **できないことを書く** —— 設定画面にもストアの説明にも | 過度な期待を生まず、果たせない約束で低評価を受けることもない |
| **戻る道を作らない** —— 回復コードなし、リセット API なし、ロックはブラウザ再起動をまたいで残る | 迂回できる布は布ではない。パスワードを忘れたら拡張機能を削除するしかなく、その旨はどの画面にも書いてある |

## 機能一覧

### 🆓 無料機能

| 機能 | 内容 |
|---|---|
| ワンクリックロック | ツールバーのボタン。キーボードショートカットは登録しない |
| 除外リスト | 最大 10 ドメインを読めるままにし、それ以外を覆う |
| ロスレスなオーバーレイ | http/https のタブをその場で覆う。再読み込みなし |
| 操作の遮断 | 覆われたページではクリック、スクロール、キー入力、ドラッグ、コピー、右クリックが止まる。ロック時にフォーカスをオーバーレイへ引き戻すので、iframe 内のエディタにキー入力が漏れない |
| 新規タブとアドレスバーの捕捉 | ロック中に開いたタブ、新しいウィンドウ、手入力の URL を捕捉 |
| パスワード解除 | PBKDF2-SHA256、310,000 回、ランダムソルト、定数時間比較 |
| 再起動後もロック | 状態は `storage.local` に保存され、ブラウザを再起動しても解除されない |
| 回復手段なし | パスワードを忘れた場合の唯一の方法は `chrome://extensions` での削除 |
| アイドル自動ロック | ブラウザ標準のアイドル検出を使用 |
| 段階的な待機 | 5 回失敗で 30 秒、その後 2 分、10 分、30 分、最後は 1 時間。解除もパスワード変更も同じカウンターで数える |
| タブタイトルの非表示 | ロック中はタブバーとウィンドウタイトルに、読んでいたページではなく中立的な名前を表示 |
| 右クリックメニュー | ポップアップを開かずに「すべてロック」「このサイトは表示したまま」 |
| 大きな時計 | ロック画面の時計、12/24 時間制、日付は任意 |
| 6 言語 | English、中文、日本語、Deutsch、Español、Français |

### ⭐ Pro 機能（ライセンスが必要）

| 機能 | 内容 |
|---|---|
| 対象を絞ったロック | ドメインリストを「のみ覆う」モードへ。社内ネットワークだけを覆い、他は読めるままに。右クリックメニューからも切り替え可。無料版は 10 ドメインまでで、常に「除外以外すべて覆う」 |
| 定刻ロック | 毎日（または平日のみ）決まった時刻にすべてを覆う。1 回限りのアラームで、発火のたびに次を予約。ブラウザを閉じていた間に過ぎた時刻は、起動時に遡ってロックしない |
| パスワード省略の時間枠 | 本当に解除した直後の数分間は、もう一度ロックしてもパスワードなしで外せる。この省略は自動延長されず、ブラウザ再起動で必ず要求され、パスワード変更で即座に無効になる |
| 生体認証による解除 | Windows Hello / Touch ID（WebAuthn）。パスワードは常にフォールバック。**入力の手間を省く近道であって、2 本目の鍵ではありません**：検証はロック画面で行われ、そこで DevTools を開ける人は同じメッセージを送れます（キーボードの前にいる人と同じ強さ）。境界はあくまでパスワード検証です |
| フォーカス喪失ロック | 他のアプリに切り替えて数秒後にロック |
| システムロック連動 | OS のスクリーンロックに追従 |
| 起動時ロック | ブラウザ起動後の最初の表示でパスワードを要求 |
| 目隠しカーテン | ロックせず現在のページをぼかす。クリックで戻る |
| 偽装ページ | 覆われたページが、明らかなロック画面ではなく普通の「このサイトにアクセスできません」に見える。「再読み込み」でロック画面へ |
| ロック記録 | この端末での解除試行を記録。パスワード変更フォームでの照合も含む |
| 壁紙とメッセージ | 6 種類のグラデーションまたは自分の画像、ロック画面の文言も変更可 |
| 端末間同期 | ロック画面の見た目、時計、自動ロック設定**およびドメインリスト**が `chrome.storage.sync` で同期される（Chrome は Google、Edge は Microsoft、Firefox は Firefox Sync）。変更は保存の少し後に自動で送信され、相手が書けばすぐ取り込む。パスワードは同期しない。アップロードした壁紙は 1 項目 8KB の容量を超えるため、内蔵グラデーションのみ同期される |

## 使い方

### 最初の設定

1. ツールバーのアイコンをクリック → **パスワードを設定**。回復コードはありません。パスワード自体を安全な場所に控えてください。
2. 席を離れるときに **今すぐロック** をクリック。
3. ロック画面でパスワード（Pro なら生体認証）を使って解除します。

### ロック範囲の設定

ドメインの照合はドット境界つきの末尾一致です。`example.com` は `example.com`、`www.example.com`、`a.b.example.com` を覆いますが、`notexample.com` は覆いません。スキーム、先頭の `www.`、パス、ポート、ワイルドカード接頭辞は自動で取り除かれ、単なる `com` は拒否されます。

ホスト名を持たないページ（`chrome://`、`file://`、`about:blank`、ローカルの PDF、拡張機能ページ）はリストに関係なく常に覆われます。リストが効くのは http と https だけです。

### パスワードを忘れた場合

方法は 1 つだけ：**`chrome://extensions` で拡張機能を削除し、入れ直す。**

壁紙とすべての設定も一緒に消えます。回復コードもリセット API も、解除を手伝えるサポートもありません —— 裏口のあるロックはロックではないからです。ブラウザを閉じても無駄です。ロック状態は `storage.local` にあり、再起動しても残ります。

ロック画面の「パスワードを忘れた」パネルは `chrome://extensions/?id=<この拡張機能>` へ直接リンクするので、行き止まりにはなりません。近道がないだけです。

## 仕組み

```
トリガー（ボタン / 右クリックメニュー / アイドル / フォーカス喪失 / システムロック / 起動 / 定刻）
  → ロック状態を storage.local に書き込み（ブラウザ再起動をまたいで維持）
  → 各 http(s) タブへ：tabs.sendMessage({type:'veil:lock'}) → オーバーレイを注入
  → 注入できないタブ：URL を覚えて tabs.update(lock.html)
  → tabs.onCreated / tabs.onUpdated が新しく現れるものを捕捉し続ける
  → windows.onCreated が Ctrl+N、「新しいウィンドウで開く」、シークレットを覆う
  → chrome://extensions/?id=<自身> だけが通過を許された内蔵ページ（削除手段を常に確保）
解除
  → 拡張機能ページでパスワード / WebAuthn を検証
  → 状態を消去、オーバーレイを除去、置き換えたタブを元の位置に戻す
```

知っておきたい設計上の判断：

- **パスワードは拡張機能のページでしか入力しません。** ウェブページの JavaScript は入力欄を見ることができず、どのサイトも盗み取れません。
- **ハッシュ化は service worker で行います。** 保存するのは `{salt, iter, hash}` だけで、パスワード自体はどこにも書かれません。
- **定数時間比較。** ハッシュの比較から時間情報が漏れません。
- **オーバーレイは閉じた shadow root の中にあります。** ページのスクリプトは中に入れず、内部の見た目も変えられません。ただしホスト要素はページの文書にあるため、サイトのスタイルシートからは狙えます。だから重要なプロパティはインラインの `!important` で書き、削除・非表示にされたら番人が掛け直します。

## よくある質問

**ブラウザを閉じてもロックは残りますか？** 残ります。状態は `storage.local` にあるため、次に開いたときも解除するまでロックされています。

**セキュリティ製品ですか？** いいえ。通りがかりの人からタブを隠すものです。端末を制御できる人は `chrome://extensions` で無効化し、別のプロファイルを使い、タスクマネージャーでブラウザを終了できます。そのすべてがストアの説明にも書かれています。

**パスワードの回復機能がないのはなぜ？** 回復コードは 2 本目の鍵であり、2 本目の鍵は裏口です。唯一の方法は拡張機能の削除で、それはロック画面にも書かれています。

**生体認証は 2 つ目の入り口ですか？** 近道であって、2 本目の鍵ではありません。パスワード検証は service worker にあり、パスワードを送る 2 か所（解除とパスワード変更）が同じカウンターと待機を通ります。パスワード省略の窓はパスワード検証を一切行いません。本物の解除から数分間だけ有効で、履歴に `quick` の 1 件を残します。ただし拡張機能のページで DevTools を開ける人は拡張機能自身のメッセージ API を叩けます。これはどの拡張機能にも防げません。生体認証は「入力が減る」であって「より安全」ではありません。

**5 回間違えるとどうなりますか？** 30 秒待機、その後 2 分、10 分、30 分、最後は 1 時間おき。カウンターは端末ごとで、ロック記録に表示されます。

**何かをアップロードしますか？** ページ内容、URL、キー入力、スクリーンショットのいずれも送信しません。外部への通信はライセンスの有効化と検証だけです。

**無料版でドメインが 10 件までの理由は？** 無料モードは「除外以外すべて覆う」で、短いリストで現実的な用途（ウェブメール、カレンダー、読んでいるページ）は足ります。逆の「のみ覆う」は仕事用ノートPCで必要になる機能なので Pro に含まれます。

**1 つのライセンスを 2 つのブラウザで使えますか？** 使えます。1 つのライセンスで 2 つのブラウザを有効化でき、片方から外せばその枠は再び空きます。

## プライバシー

- 解析なし、テレメトリなし、広告なし、アカウント不要。
- ページ内容、URL、タイトル、キー入力はブラウザの外に出ません。
- 壁紙とロック画面のメッセージは端末内に留まります。アップロードした画像は縮小され、このブラウザプロファイルに保存され、どこにも送信されません。
- 端末間同期（Pro）は `chrome.storage.sync`、つまりブラウザ自身の同期経路を使います。この経路に私たちのサーバーはなく、読むこともできません。パスワードは意図的に同期から除外され、アップロードした壁紙は容量を超えるため、同期されるのは設定項目だけです。
- 外部への通信はライセンスの有効化 / 検証のみで、キーを貼り付けたときに限られます。

- [プライバシーポリシー全文](https://annmax1983.github.io/vkt-veil-mate/privacy-policy.html)

### 権限

| 権限 | 用途 |
|---|---|
| `storage` | 設定（ハッシュのみ）、永続的なロック状態、`storage.sync` 経由の Pro データ保存 |
| `tabs` | タブを覆い、ロック中の新しいタブと手入力の URL を捕捉 |
| `windows` | ウィンドウのフォーカス変化を検出し、フォーカス喪失ロックを実現 |
| `idle` | アイドル自動ロック |
| `alarms` | 定刻ロックと遅延フォーカスロック（バックグラウンドが起き続ける必要がありません） |
| `contextMenus` | 右クリックメニュー（すべてロック / このサイトは表示したまま） |
| `https://api.annmax1983.com/*` | ライセンスの有効化と検証のみ |

コンテンツスクリプトは `http://*/*` と `https://*/*` で動作し、することは 1 つだけです。service worker に頼まれたときにオーバーレイを描きます。
